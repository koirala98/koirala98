### 💼 Auto Job Hunter
> AI-powered job search platform for international CS students on OPT/STEM OPT. Multi-agent system that discovers jobs, ranks by fit and H-1B sponsorship likelihood, tailors resumes/cover letters, tracks applications, and monitors OPT deadlines.

- 11-agent swarm orchestrated via Ruflo (claude-flow) with hierarchical topology
- Scoring algorithm weighs resume match, skills, visa likelihood, location, salary, and posting freshness
- Human-in-the-loop safety — all external actions (applications, emails, outreach) require explicit user approval
- OPT deadline tracker with configurable alerts at 90/60/30/14/7 days

[`Private Repository`](https://github.com/koirala98/Job-Hunter)

**Tech:** Next.js 14 · React · TypeScript · Tailwind CSS · PostgreSQL · Prisma · Claude API · Playwright · Clerk · Sentry
